RUNTIME POLICY

运行时管理

配置当前唯一的子进程 Mock 运行时资源上限和网络策略。配置由管理员统一维护。

本地 Python 子进程（Mock）
subprocess-mock
当前唯一运行时
范围：1–3600 秒；超时后终止子进程。
子进程 Mock 尽可能映射为 CPU 时间限制，不等同容器 CPU quota。
平台支持时映射为进程地址空间限制。
网络规则会保存并显示，但当前子进程 Mock 不具备网络隔离能力，规则尚未强制执行。
修改适用于后续运行，不影响正在执行的子进程。
生产环境策略设计：最长运行时间、CPU、内存、外网白/黑名单是运行时策略配置。当前仅在本地子进程上做有限映射；真正执行网络策略需要容器/VM 层网络隔离，不能依赖 Agent 或 Python 代码自律。
